🚀 Hackathon Catalyst
Your instant idea, tech stack, and collaboration hub.

🔗 Live Link on Render: https://hackathon-catalyst-2.onrender.com/


Hackathon Catalyst is a productivity engine built specifically for hackathon participants. 
It solves the three biggest hurdles of any 24-hour sprint: Finding an idea, Setting up a tech stack, and Staying coordinated.
The app features a high-visibility "Command Center" dashboard with a real-time countdown, a filtered project idea generator
and a secure team chat room.
